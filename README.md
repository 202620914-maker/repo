# 기능톡

용접기능사·에너지관리기능사·공조냉동기계기능사·전산응용기계제도기능사·가스기능사·설비보전기능사·위험물기능사·전기기능사·배관기능사·승강기기능사 필기 문제를 풀고 학교 친구들과 학습 시간을 공유하는 작은 웹앱입니다. 각 분야별 60문항을 제공하며 퀴즈 풀이 경과 시간을 확인할 수 있습니다.

## 실행

Node.js 18 이상이 필요합니다. 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
node server.js
```

브라우저에서 `http://localhost:3000`을 엽니다. 학교 네트워크의 다른 기기에서 접속할 때는 서버 PC의 내부 IP 주소와 `:3000` 포트를 사용하세요. 학교 방화벽에서 해당 포트의 접속을 허용해야 합니다.

## 익명 학습 기록

- 로그인이나 가입 없이 바로 문제를 풀 수 있습니다. 브라우저마다 익명 식별자를 만들어 학습 기록을 구분합니다.
- 같은 서버에 접속한 학생의 오늘·누적 학습 시간이 학교 대시보드에 익명으로 표시됩니다.
- 공부 시간은 페이지가 보이고 최근 사용자 입력이 있을 때 약 15초 간격으로 기록됩니다.
- 학교 이름은 기본 `우리 학교`입니다. 서버 환경 변수 `SCHOOL_NAME`으로 표시 이름을 바꿀 수 있습니다.
- 학습 기록은 서버의 `data/school-data.json`에 저장됩니다. 이 파일을 정기적으로 백업하세요.

## 배포

모든 학생이 함께 이용하려면 서버를 학교에서 접근 가능한 상시 실행 환경에 배포해야 합니다. 공개 인터넷에 배포할 때는 HTTPS를 적용하세요.

문항은 기초 개념 학습용 자체 제작 문항이며 실제 시험 문제와 다를 수 있습니다.
